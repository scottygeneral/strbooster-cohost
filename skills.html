◆Install A Skill

Three Steps. Two Minutes.

  • 1
    Download The .zip. Each skill is one .zip file. Don’t unzip it.
  • 2
    Upload It To Claude. In Claude, open Settings, find Skills, and upload the .zip. Turn on code execution if Claude asks, since some skills run a small script.
  • 3
    Just Ask. Say what you want, like “build my business brain” or “make a guest intelligence report for this listing.” Claude picks the skill up on its own.

Prefer to read first? Every skill is plain text. Open SKILL.md here or browse the folder on GitHub. The .md files also work dropped into a Claude project.

Skill Questions.

What is a Claude skill?

A Claude skill is a small folder of instructions, and sometimes scripts and templates, that teaches Claude to do one job the same way every time. These skills cover short-term rental work such as the business brain, brand guide, guest intelligence report, channel plan, marketing plan and guest experience. They are free and open on GitHub.

How do I install a Claude skill?

Download the skill’s .zip without unzipping it. In Claude, open Settings, find Skills and upload the .zip. Then ask for the job in plain words and Claude uses the skill on its own.

Are these skills free?

Yes. Every skill is free to download, use and change. There is no sign-up, and nothing is for sale.

Which skill should I start with?

Start with The Brain. It builds your business-brain.md file with your goals, numbers and rules, and the other skills read that file so their answers fit your business.

Can I use a skill without uploading it?

Yes. Every skill is plain text. You can read SKILL.md on the site or on GitHub, and the single-file .md kits also work dropped into a Claude project.

Can I change a skill to fit my business?

Yes. Edit the text in SKILL.md, zip the folder again and upload it. Every skill is open on GitHub, so you can see exactly what it tells Claude to do.
